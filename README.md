## 📌 Objetivo

O objetivo deste projeto é conscientizar sobre a importância do agronegócio para a economia brasileira, destacando os impactos ambientais causados pelo uso excessivo de agrotóxicos e apresentando alternativas sustentáveis para equilibrar produção agrícola e preservação ambiental.

---

## 🌍 Justificativa

O agronegócio é essencial para o Brasil, pois gera empregos, renda e alimentos. No entanto, seu crescimento precisa ocorrer de forma responsável. Este projeto busca incentivar a reflexão sobre práticas agrícolas sustentáveis e o uso consciente dos recursos naturais.

---

## 🧠 Conteúdo abordado

O site apresenta:

- Importância do agronegócio  
- Problemas causados pelo uso excessivo de agrotóxicos  
- Impactos no solo, água e saúde humana  
- Alternativas sustentáveis:
  - Agroecologia  
  - Controle biológico  
  - Plantio consorciado  
  - Biofertilizantes  
- Conscientização ambiental

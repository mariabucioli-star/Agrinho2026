# 🌿 Agro Forte, Futuro Sustentável

> Projeto desenvolvido para o **Concurso Agrinho 2026** — SENAR-PR  
> Tema: **"Agro Forte, Futuro Sustentável: equilíbrio entre produção e meio ambiente"**  
> `#agrinho2026`

---

## 🎯 Objetivo

Conscientizar sobre os impactos do uso excessivo de agrotóxicos na agricultura brasileira, apresentando soluções sustentáveis como agroecologia, controle biológico e tecnologias de precisão — promovendo o equilíbrio entre alta produtividade e preservação ambiental.

## 💡 Justificativa

O agronegócio é responsável por cerca de 33% do PIB brasileiro e 19 milhões de empregos. Porém, o uso descontrolado de agrotóxicos degrada o solo, contamina a água e representa risco à saúde humana. Este projeto visa informar e engajar o público sobre caminhos sustentáveis para o campo.
